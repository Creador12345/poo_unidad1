# Prueba audio visual

## Objetivo y propósito
crear 3 clases: autor, temporada, investigador, adicional agregar 2 clases mas de forma creativa, con el fin de comprender y usar los conceptos de: herencia, asociación, etc. 

## Clases nuevas y funcionalidades
Actor: la cual permite crear varios actores.
temporada: permite poner el numero de temporadas que tiene una serie, cantidad de episodios y el año que se estreno dicha serie.
Investigador: permite asignar un investigar, su nombre, especialidad y institución de ser necesario
VideosTiktok: permite ver el usuario, cantidad de likes y la musica utilizada en el video.
RealIg: permite ver la cuenta, cantidad de vistas y hastag de un video.
